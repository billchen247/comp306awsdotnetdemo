### Before (Original Program.cs)
```csharp
public class Program
{
    public static void Main(string[] args)  // ? Non-async
    {
        // ... setup ...
        app.Run();  // ? Blocking
    }
}
```

### After (Updated Program.cs)
```csharp
public class Program
{
    public static async Task Main(string[] args)  // ? Async
    {
        // ... setup ...
        
        // ? NEW: Seed database on startup
        using (var scope = app.Services.CreateScope())
        {
            var seeder = scope.ServiceProvider.GetRequiredService<CityInfoDbSeeder>();
            await seeder.SeedAsync();
        }
        
        await app.RunAsync();  // ? Async
    }
}
```

## ? Pre-Startup Checklist

```
Before running: dotnet run

? Connection string in appsettings.json looks correct
  ?? Should be: (localdb)\mssqllocaldb
  
? SQL Server (LocalDB) is available
  ?? Included with Visual Studio
  
? Project builds without errors
  ?? Run: dotnet build
  
? Dependencies are restored
  ?? Run: dotnet restore
  
? Port 7000 is available
```
