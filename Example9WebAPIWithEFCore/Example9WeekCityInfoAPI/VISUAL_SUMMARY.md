## ?? Usage Examples

### Create City
```bash
curl -X POST https://localhost:7000/api/cities \
  -H "Content-Type: application/json" \
  -d '{"cityName":"Boston","description":"The Hub"}'
# Returns: 201 Created with Location header
```

### Get All Cities
```bash
curl https://localhost:7000/api/cities
# Returns: 200 OK with array of cities
```

### Partial Update with JSON Patch
```bash
curl -X PATCH https://localhost:7000/api/cities/1 \
  -H "Content-Type: application/json-patch+json" \
  -d '[{"op":"replace","path":"/description","value":"Updated"}]'
# Returns: 204 No Content
```

### Create Point of Interest
```bash
curl -X POST https://localhost:7000/api/cities/1/pointsofinterest \
  -H "Content-Type: application/json" \
  -d '{"nameofPOI":"Times Square","description":"Famous place"}'
# Returns: 201 Created with Location header
```
